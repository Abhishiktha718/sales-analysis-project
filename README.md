# 📊 Sales Analysis Project

## 📌 Overview

This project analyzes retail sales data to identify trends, profitability, and business insights using **Excel, SQL, and Python**.

The goal is to understand sales patterns, category performance, and seasonal trends to support better decision-making.

---

## 🛠️ Tools & Technologies

* **Excel** – Data cleaning and pivot tables
* **SQL (MySQL)** – Data querying and aggregation
* **Python (Pandas, Matplotlib)** – Data analysis and visualization

---

## 📂 Dataset

* Global Superstore dataset
* Contains information on sales, profit, region, category, and order dates

---

## 🔍 Key Analysis Performed

* Data cleaning and preprocessing
* Sales analysis by region
* Profit analysis by category
* Monthly sales trend analysis
* Data visualization using Python

---

## 📈 Key Insights

* Technology category generates the highest profit
* Furniture category shows significantly lower profitability
* Sales peak towards the end of the year (seasonal trend)
* Monthly sales fluctuate, indicating varying demand patterns
